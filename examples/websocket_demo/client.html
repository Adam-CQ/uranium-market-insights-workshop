Try disconnect and restart

  1. Click Connect. Observe the sequence and synthetic values received without a new HTTP request per message.
  2. Click Disconnect. Automatic retry stops until you click Connect again.
  3. Connect again, then stop the example server with Ctrl+C. Keep this page open; its status shows disconnect/retry.
  4. Restart the same server command. With automatic reconnect enabled, this page reconnects with a new connection ID and sequence 1.

Retries wait 1, 2, 4, then at most 8 seconds between attempts. Reconnecting starts a new mock stream; missed messages are not replayed. Published monthly/annual uranium data uses ordinary HTTP in our dashboard.
